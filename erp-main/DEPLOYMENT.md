# Render Deployment Guide

This ERP application is configured for deployment on Render using a `render.yaml` blueprint file.

## Architecture

The application is deployed as **two separate services**:

1. **Backend Service** (`erp-backend`)
   - Node.js/Express API
   - Location: `backend/` directory
   - Port: 5000
   - Health check: `/api/health`

2. **Frontend Service** (`erp-frontend`)
   - Next.js application
   - Location: `frontend/` directory
   - Automatically connects to backend API

## Deployment Steps

### 1. Prerequisites

- GitHub/GitLab account with this repository
- Render account ([render.com](https://render.com))
- MongoDB Atlas database (or other MongoDB host)

### 2. Deploy to Render

#### Option A: Using Blueprint (Recommended)

1. Push this repository to GitHub/GitLab
2. Go to [Render Dashboard](https://dashboard.render.com)
3. Click **"New"** → **"Blueprint"**
4. Connect your repository
5. Render will automatically detect `render.yaml` and create both services
6. Add required environment variables in the dashboard:
   - `MONGODB_URI` for the backend service

#### Option B: Manual Deployment

**Backend Service:**
1. New → Web Service
2. Connect repository
3. Configure:
   - **Name**: `erp-backend`
   - **Root Directory**: `backend`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
4. Add environment variables (see below)

**Frontend Service:**
1. New → Web Service
2. Connect repository
3. Configure:
   - **Name**: `erp-frontend`
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
4. Add environment variables (see below)

### 3. Environment Variables

#### Backend (`erp-backend`)

Required:
- `MONGODB_URI` - Your MongoDB connection string
- `JWT_SECRET` - Auto-generated by Render (or set manually)

Optional (defaults provided):
- `NODE_ENV` - `production`
- `PORT` - `5000`
- `JWT_EXPIRE` - `7d`
- `COOKIE_EXPIRE` - `7`
- `FRONTEND_URL` - Auto-linked to frontend service

#### Frontend (`erp-frontend`)

Auto-configured:
- `NODE_ENV` - `production`
- `NEXT_PUBLIC_API_URL` - Auto-linked to backend service

### 4. Database Setup

1. Create a MongoDB Atlas cluster (or use existing MongoDB)
2. Whitelist Render's IP addresses (or allow all: `0.0.0.0/0`)
3. Get connection string
4. Add to Render backend service as `MONGODB_URI`

### 5. Health Checks

Ensure your backend has a health check endpoint:

```javascript
// backend/src/routes/health.ts (or similar)
router.get('/api/health', (req, res) => {
  res.status(200).json({ status: 'ok' });
});
```

## Post-Deployment

### Verify Services

1. Backend health check: `https://erp-backend.onrender.com/api/health`
2. Frontend: `https://erp-frontend.onrender.com`

### Update Frontend API URL

If needed, update the frontend `.env` file locally to match:
```
NEXT_PUBLIC_API_URL=https://erp-backend.onrender.com
```

### Monitoring

- View logs in Render dashboard for each service
- Set up alerts for downtime
- Monitor database connections

## Troubleshooting

### Common Issues

**"Cannot find package.json"**
- Ensure `rootDir` is set correctly in `render.yaml`
- Backend: `rootDir: backend`
- Frontend: `rootDir: frontend`

**Database connection failed**
- Verify `MONGODB_URI` is correct
- Check MongoDB Atlas network access whitelist
- Ensure database user has proper permissions

**Build failures**
- Check build logs in Render dashboard
- Ensure all dependencies are in `package.json`
- Verify Node version (>=18.0.0)

**504 Gateway Timeout**
- Backend may be slow to start
- Check for errors in backend logs
- Verify database connectivity

### Free Tier Limitations

Render's free tier:
- Services spin down after 15 minutes of inactivity
- First request after sleep takes ~30-60 seconds
- 750 hours/month per service

## Local Development

Use the root `package.json` scripts:

```bash
# Install dependencies
npm run install:all

# Run both services
npm run dev

# Build both services
npm run build
```

Or run individually:

```bash
# Backend only
cd backend && npm run dev

# Frontend only
cd frontend && npm run dev
```

## Updates & Redeployment

Render auto-deploys on git push to main branch (default).

To manually redeploy:
1. Go to Render dashboard
2. Select service
3. Click "Manual Deploy" → "Deploy latest commit"
